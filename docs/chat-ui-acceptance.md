# 对话界面与 Markdown 验收

日期：2026-10-16。

## 设计依据

使用 [UI UX Pro Max 官方 skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/.claude/skills/ui-ux-pro-max/SKILL.md)，结合现有 React 工作台与主题变量实现。

- `chat typography readability --domain ux`：采用行高和文字对比度两项匹配建议；数字格式建议与本次目标无关，未采用。
- `memo streaming message --stack react`：仅缓存有 Markdown / KaTeX 解析成本且输入稳定的正文组件，避免历史回答随其他消息的增量重复解析；保持流式正文即时更新。
- 参考 web/desktop 的键盘焦点、24px 最小指针目标、标签显隐、窄窗口与减少动态效果规则。

## 修改

1. 提问与回答均渲染 Markdown，统一标题、列表、引用、任务列表、表格、行内代码与公式排版。
2. 修复 `**摘要——**后文` 一类中文标点紧邻正文时暴露 Markdown 标记的问题。只转换未解析的中文文本节点，不修改原始回答；保留显式转义、代码和数学内容。
3. 代码块显示语言与复制按钮；表格在局部容器内横向滚动并支持键盘聚焦。源码和预览可逐条切换。
4. 正文采用 14px，历史页 15px；重新整理消息间距、标题层级、提问气泡、输入框标签及操作按钮。
5. 本机 Codex 连接状态简化展示，邮箱和套餐移到账号菜单。向上浏览历史时保留位置，可点击「回到最新」。
6. 所有新增颜色使用共享主题变量；窄窗口上下分屏时，AI 区域分配更多高度。

## 已验证

独立 `artifacts/chat-design-qa-data/` 资料库使用合成 PDF 与 Codex 协议仿真子进程，不发送个人文献或消耗真实 AI 额度。

- 历史页与阅读侧栏的 Markdown、中文加粗、标题、列表、表格、代码与 KaTeX。
- 复制代码的实际剪贴板内容为完整源码；源码切换后仍可返回预览。
- 保存关联笔记后，加粗、表格、代码和公式保留，静态笔记不保存交互按钮。
- 新建提问后出现流式输出状态；停止后保留部分回答与中断状态。
- 浅色、暗色、阅读专注模式；700×820 与 375×820 窗口。375px 时对话区宽度未溢出，表格仅在自身容器内滚动；检查后恢复默认窗口。
- 浏览器未记录前端错误。截图：`artifacts/chat-ui-markdown-dark.png`。
- 抽样测量正文、输入标签和代码操作文字的实际配色：浅色最低对比度 5.43:1，暗色最低 8.22:1；不据此声明整站已完成无障碍认证。

`npm run build`：TypeScript 与 Vite 生产构建通过，保留既有 Word 编辑内核的大资源包提示。
