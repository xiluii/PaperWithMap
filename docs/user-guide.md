# Paperly 使用与开发指南

[返回项目首页](../README.md) · 本页保留完整功能说明、操作方法与开发配置。

基于无限画布与知识图谱的本地文献管理平台，将论文、文字卡片与手写笔记连接在同一研究空间中。

目前以 **React 浏览器前端 + Node.js 本地服务** 的形式运行，面向桌面端研究与阅读场景。工作区、PDF、Word、PPT、图片和笔记保存在本机文件夹，无需注册或登录。

可选的阅读 AI 默认通过 **本地 Codex App Server 桥接**，使用本机 Codex 的 ChatGPT 登录及账号获准的 Codex 额度。不需要填写 API Key，不会自动切换为单独计费的 API；文献库本身继续免登录。

## 功能特性

### 无限画布与知识关联

- 拖入或批量导入本地 PDF，自动提取标题、作者与年份，并生成首页预览和文献卡片。
- 同时支持 DOC/DOCX、PPT/PPTX、JPG/JPEG/PNG，混合拖入即可生成文件卡片；支持按类型筛选、原文件名和备注检索。
- 自由拖拽文献卡片和文字卡片，支持网格吸附、平移、缩放及缩略导航。
- 使用四向连接锚点建立有向或无向连线，并为关系命名。
- 在自由画布、时间轴和知识图谱之间切换；时间轴可按发表年份或阅读日期排列。
- 为白板设置默认卡片外观，也可逐张选择是否显示作者、关键词、图片预览、年份、阅读状态、期刊 / 会议和摘要。
- 支持卡片 60%–200% 等比例缩放；文字和预览同步变化，时间轴按实际尺寸调整间距。
- 文字卡片支持富文本排版，包括字体、字号、颜色、高亮、加粗、斜体和列表。

### PDF 连续阅读与批注

- 选择使用系统默认 PDF 软件或在平台内打开。
- 整篇 PDF 连续排列，可直接滚动到文章末尾；页码随滚动更新，支持阅读缩放。
- 支持不同页面尺寸和旋转页，按视野绘制附近页面，减少长文档的画布内存占用。
- 提供钢笔、荧光笔、压感、颜色、粗细、整笔橡皮及撤销 / 重做。
- 点击「保存 PDF」将所有页面的矢量墨迹写入 PDF；在其他阅读器中也能看到批注。
- 保存时保留导入原件、当前版本和上一版本；重复保存不会重复叠加墨迹。

### 手写笔记与跨页联动

- 独立手写笔记库，支持新建、重命名、搜索、排序、回收站及恢复。
- 支持数位板真实压感、鼠标模拟压感和「仅手写笔输入」模式。
- 提供纯白、纯黑与黑板绿三种背景，支持导出 PNG。
- 一张文献或文字卡片可关联多份笔记，通过卡片悬浮操作栏快速查看。
- 阅读器提供论文、手写笔记、AI 对话三个独立分页，可切换为三栏并排；新建笔记自动关联当前文件。
- 可调用已有笔记，将笔迹副本放入任意 PDF 页面后保存。

### Word 编辑、PPT 阅读与图片

| 类型 | 平台内 | 外部与保存 |
| --- | --- | --- |
| Word `.docx` | SuperDoc 兼容编辑内核，直接修改正文；字体、字号、颜色、段落、列表、图片、表格、查找替换、撤销重做 | 自动保存真实 DOCX，支持 Ctrl+S、下载和默认软件打开 |
| 旧 Word `.doc` | 本地转换为 DOCX 工作稿后直接编辑，保留导入的 DOC 原件 | 后续修改保存为 DOCX；工作稿和原卡片保持同一文件 ID |
| PowerPoint `.ppt/.pptx` | 本地生成静态 PDF 预览，全部幻灯片连续滚动；批注保存至预览 PDF | 默认软件打开 PPT 原件，网页批注不回写 PPT |
| 图片 `.jpg/.jpeg/.png` | 预览、透明底、适应窗口、100%、25%–800% 缩放、拖动平移、显示名称与备注 | 原图保留，名称和备注自动保存在工作区 |

Word 直接编辑过程中不生成 PDF。Word 和图片均支持左侧内容、右侧手写笔记；新笔记自动绑定文件，也可以关联已有笔记。各种文件卡片都能与其他文件或文字卡片连线，并沿用字段显隐、卡片缩放、分屏比例与专注模式。

DOCX 编辑和图片无需额外 Office 服务。旧 DOC 与 PPT 需要本地转换器：支持标准 Office16 安装目录内的 Microsoft Word/PowerPoint，或通过 `PAPERLY_SOFFICE_PATH` 指定 LibreOffice。当前 Windows 环境已使用 Word 自带 `wordconv.exe` 和 PowerPoint 实际验证旧 DOC、PPT、PPTX 转换。

```powershell
# 可选：使用本机已有的 LibreOffice；设置后重新启动服务
$env:PAPERLY_SOFFICE_PATH = 'C:\Program Files\LibreOffice\program\soffice.com'
npm run dev
```

缺少转换器或转换失败时，原件仍保存在本地，可通过默认软件打开，并从卡片关联手写笔记；配置完成后点击重试。Word 保存发生版本冲突时，当前编辑内容保留，可先下载编辑稿再重新打开。默认软件打开的是平台管理的本地文件副本。

### 文献库与本地保存

- 多白板、文献库、收藏、最近阅读、按标题、作者或标签搜索与阅读状态筛选。
- 工作区和独立笔记自动保存到本地；PDF 批注使用显式保存，并在未保存退出时提示。
- 首次连接本地资料库时迁移原有浏览器 IndexedDB 数据。
- 白板结构可导出为 JSON，包含相关手写笔记；PDF 二进制文件需随数据目录另行备份。

### 外观与专注模式

- 点击顶部太阳 / 月亮按钮选择浅色、暗色或跟随系统。偏好保存在当前浏览器，刷新后保留；同一来源的其他标签页同步切换。
- 白板、时间轴、知识图谱、文献库、收藏、最近阅读、笔记库、对话历史和各类弹窗均适配暗色界面。
- 阅读器、手写笔记和隐藏顶栏后的白板保留主题入口，可在专注模式中切换。
- PDF / PPT 原文、Word 正文、图片与手写画布保持原有内容颜色；界面主题不修改文件、墨迹或导出结果。笔记的纯白、纯黑和黑板绿底色独立设置。

### 光标与右键菜单

- 可点击控件使用指针，文本输入与 PDF 选词使用文本光标，卡片拖拽使用抓手，连线锚点使用十字光标，卡片缩放与分屏分别使用斜向和横向缩放光标。
- 手写钢笔、荧光笔和橡皮各有独立光标，笔尖标记对应输入位置。按空格或使用抓手时切换为平移光标；禁用操作显示禁止光标。
- 画布空白处右键可在当前位置新建文字卡片、导入文件、撤销重做、全选、适应内容、切换吸附和专注模式。右键用于菜单；平移使用抓手、空格拖动、鼠标中键或滚轮。
- 卡片右键可打开文件、调用默认软件、收藏、查看或新建关联手写笔记、设置显示、复制和移除。多选时可复制或移除整组选中卡片。复制仍引用原本的本地文件；组内关系一并复制，组外关系不会额外生成。移除卡片保留原文件，可撤销。
- 连线右键可编辑关系、切换有向连接或删除连线；文献库提供打开、定位和收藏操作。
- PDF / PPT 阅读区右键可复制选中文字、缩放、切换批注工具、创建关联笔记、打开 AI 对话、保存、默认软件打开及切换专注模式。只有划词翻译已开启时才显示选区词典查询；关闭时不会因为右键而发送查询。
- 图片右键可适应窗口、恢复原始尺寸、放大缩小、跳转修改名称或备注、默认软件打开和下载原图。
- 手写画布右键可撤销重做、切换工具、适应全部笔迹、专注书写、关联卡片及切换底色；清空画布仍有确认，且可撤销。笔记库提供重命名、分屏、定位、移入回收站或恢复操作。
- 对话历史右键可继续对话、打开来源、重命名或打开删除确认框；生成中的对话禁用重命名和删除。
- 菜单支持 ↑ / ↓、Home / End、Enter、显示的快捷键以及 Shift + F10 唤起；Esc 或 Tab 关闭菜单并返回原焦点。阅读器处于专注模式时，菜单中的 Esc 只关闭菜单。点击外部、滚动页面、窗口失焦或调整大小会关闭菜单；滚动菜单自身不会关闭。
- 输入框、富文本编辑区、链接与 Word 正文保留原生或编辑内核的右键菜单。菜单与操作提示适配浅色、暗色和专注模式。

### 划词翻译

- 平台内的 PDF、PPT 阅读页及 Word 编辑页顶部提供「划词翻译」开关，默认关闭，并在当前浏览器记住偏好；收起侧栏或进入专注模式后仍可切换。
- 开启后拖选或双击单词、短语，即可查看有道词典的音标与中英释义。PDF / PPT 需使用「阅读」工具；扫描图片没有文字层时无法直接划词。Word 通过编辑内核的只读选区接口查询，不修改正文。
- 单次选区限 120 字符、20 个词；词典不收录的词条会明确提示，不自动调用 AI 或翻译整段。可点击「完整词条」在有道网站查看详情。
- 关闭开关立即关闭浮层并取消正在进行的查询，之后选词不发送词典请求。点击浮层外、滚动页面或按 Esc 可收起结果；网络失败可重试。
- **开启时仅将选中的文字联网发送至有道词典**，不上传整份文献、文件名、笔记、账号或聊天记录，不调用 GPT，也不消耗 Codex 额度。已发出的查询无法从第三方撤回；关闭后取消本地等待和后续请求。释义仅短期缓存在本地服务内存中，不写入文献、聊天或磁盘。
- 此功能采用有道词典的公开查询接口（非承诺稳定的授权开放平台 API），无需密钥；可用性取决于网络和服务提供方。

### 阅读 AI 与对话历史

- 阅读器的「论文」「手写笔记」「AI 对话」为独立分页。顶部「阅读布局」可切换研究工作区（论文居左、白板和 AI 上下排列）、三栏并排或独立分页；收起的笔记和 AI 区域可从对应分页重新打开，草稿和笔迹继续保留。
- PDF 阅读模式提供可选择的文字层；拖选文字后点击「向 AI 提问」，可仅发送选区。使用钢笔时先切回阅读工具。
- 「全文总结」提取整篇 PDF / PPT 预览文字；Word 直接读取编辑内核的当前正文；图片可发送缩放后的视觉内容。
- 「解释公式」优先使用选区；未选中文字时，PDF / PPT 会发送当前可见页的截图，适合公式或扫描页面。
- 支持流式回答、停止生成、Markdown、表格和 LaTeX 公式。失败、中断和未完成状态会保留，不会误标为成功。
- 回答可保存为画布文字笔记，与来源文献自动连线；阅读侧栏的「AI 阅读笔记」可直接回看。重复保存同一回答不会生成重复卡片。
- 主页「对话历史」展示本平台所有对话，支持全文检索、按文献筛选、每页 20 条、重命名、导出 Markdown、删除、继续提问及返回来源文献。
- 切换页面或笔记标签不会停止正在生成的回答。刷新或服务重启后可读取已保存内容并继续讨论。

首次使用：安装 Codex CLI（`npm install -g @openai/codex`），在阅读页切换「AI 对话」。已有本机 ChatGPT 登录时会自动显示账号与模型；没有登录时点击「连接本机 Codex」，在系统浏览器完成官方登录。也可使用 `codex login` 预先登录。

浏览器回调不稳定时，可选择「设备码登录」，在官方验证页面输入短期设备码。首次使用可能需在 ChatGPT 安全设置或工作区权限中启用设备码登录。登录状态与刷新令牌由 Codex 官方客户端管理，Paperly 不读取或复制其凭证文件。

账号菜单支持检测登录、刷新模型、浏览器重新登录、设备码登录、管理用量及「断开平台连接」。断开仅停止 Paperly 的桥接，不退出其他共用登录的本机 Codex；通过 Codex 更改账号会影响共用该登录的客户端。若本机只有 API Key 登录，本桥接会拒绝生成并提示改用 ChatGPT 登录。

对话、选区和用于问答的上下文保存在本地 `conversations/`。**发送提问时，相关文献内容及对话上下文会通过 Codex 联网发送至 OpenAI**；凭证不会发给前端。这不是 OpenAI 服务端零保留或完全离线的承诺。此功能不读取 ChatGPT 网页的历史记录或记忆。

每次生成使用临时 Codex 会话，以平台保存的完整本地历史重建上下文；禁用命令、插件和浏览器等工具，使用只读模式，拒绝额外工具授权。模型从官方客户端动态发现，成功完成一次推理才确认当前账号能够使用该模型。使用的是 Codex 可用额度与模型目录，受当前账号和工作区规则限制。

回答以 SSE 流式显示，收到文字增量就更新阅读页或历史页；生成时区分「正在思考」与「正在输出」，可随时停止并保留已有内容。向上滚动查看历史时不会强制拉回底部。

输入框下方的「推理」选择器可调整下一次回答的推理强度，档位与默认值来自 Codex `model/list`，并通过 `turn/start.effort` 生效。选择「模型默认」跟随当前模型的目录默认值；切换模型时只显示该模型支持的档位，并分别记住选择。偏好保存在本机浏览器；每条回答实际使用的强度随对话 JSON 与 Markdown 导出保存。较高强度通常需要更长等待时间。未提供推理档位的模型不显示选择器。协议依据见 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。

此桥接面向本机使用。官方文档限制 App Server 认证用于商业或托管服务；发布为这类服务前需另行选择获准的接入方式。参考 [Codex App Server](https://learn.chatgpt.com/docs/app-server)、[官方认证说明](https://learn.chatgpt.com/docs/auth)。原 SIWC 接入代码保留兼容和回归验证，已不作为默认连接路径。

## 技术栈

| 层次 | 技术 |
| --- | --- |
| 界面 | React 19、TypeScript、Vite |
| 无限画布与图谱 | React Flow（`@xyflow/react`） |
| PDF 解析与阅读 | PDF.js（`pdfjs-dist`） |
| PDF 墨迹嵌入 | `pdf-lib` |
| Word 正文编辑 | SuperDoc，浏览器端 DOCX 编辑与导出，关闭遥测 |

| 手写引擎 | Canvas、Pointer Events、`perfect-freehand` |
| 本地服务 | Node.js HTTP / 文件系统接口 |
| 系统文件打开 | `open` |
| 富文本清理 | DOMPurify |
| 阅读 AI | Codex App Server、stdio JSON-RPC、Codex 管理的 ChatGPT 登录、本地 SSE |
| AI 排版 | react-markdown、remark-gfm、remark-math、KaTeX |
| 自动化验证 | Vitest、Node.js Test Runner |

具体依赖版本以 [package.json](../package.json) 和 [package-lock.json](../package-lock.json) 为准。

## 快速开始

### 环境要求

- Node.js **22.18 或更新版本**，以及随 Node.js 安装的 npm。
- 支持现代浏览器 API 的桌面浏览器。
- 使用系统默认阅读器功能时，需在本机配置 PDF 文件关联。

### 开发运行

在项目根目录执行：

```sh
git clone https://github.com/xiluii/PaperWithMap.git
cd PaperWithMap
npm ci
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。开发命令同时启动前端和本地后端：

| 服务 | 默认地址 |
| --- | --- |
| Vite 前端 | `http://127.0.0.1:5173` |
| 本地文件后端 | `http://127.0.0.1:4317` |

Vite 将 `/api` 请求代理到本地后端。首次启动会创建数据目录，并提供示例研究白板。

### 构建后运行

```sh
npm run build
npm start
```

打开 [http://127.0.0.1:4317](http://127.0.0.1:4317)。此时同一个本地服务同时提供构建后的前端和文件接口。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 按锁文件安装依赖 |
| `npm run dev` | 同时启动开发前端与本地后端 |
| `npm run server` | 单独启动本地后端 |
| `npm test` | 运行单元测试与后端集成测试 |
| `npm run build` | 执行 TypeScript 检查并构建前端 |
| `npm start` | 启动本地服务，提供 `dist/` 中的前端及 API |
| `npm run preview` | 预览前端构建；文件功能仍需本地后端运行 |

`npm start` 前需要先完成构建。开发服务和构建后服务默认共用后端端口，切换运行方式前请停止旧服务。

## 工作台布局

白板顶部采用紧凑布局，文献库与笔记库优先展示搜索和内容。阅读页提供论文（Word 为文档、图片为图片）、手写笔记与 AI 对话三个独立分页；桌面默认使用研究工作区，也可三栏并排。研究工作区不足 760px、三栏布局不足 1000px 时自动分页。已有浏览器布局偏好会保留。切换分页会保留 PDF 当前页、笔记和聊天草稿。

导航、卡片详情、白板笔记和对话历史列表均可调整宽度与左右位置。鼠标靠近侧栏的内边缘时显示宽度把手，靠近顶部中间时显示位置把手；拖到工作区另一侧即可换边。阅读分栏的把手位于分隔线和标题内，可调整宽度和顺序，平时隐藏。研究工作区还可拖动白板与 AI 之间的横线调整高度，也可在「阅读布局 → 调整分栏大小」点击滑杆设置。宽度、位置、阅读顺序与布局偏好保存在当前浏览器。

键盘 Tab 也可聚焦隐藏的把手，聚焦后显示。宽度把手支持左右方向键、Home / End，Enter 或双击还原；位置把手支持左右方向键。阅读分页支持方向键切换。专注模式保留恢复入口，退出后回到原布局。布局约定见 [设计规范](design-system.md)，实机记录见 [布局验收](panel-layout-acceptance.md)。

白板与手写工具栏可收起；靠近工具栏时显示拖动把手，可拖到画布任意位置，也可用方向键微调。位置菜单提供移至顶部、底部和归位，双击把手恢复默认位置。窗口或分栏变小后，工具栏会保持在画布内。手写画布按 `R` 画矩形、`A` 画箭头，沿用笔迹保存、橡皮、撤销和导出流程。

## 基本使用

1. **创建知识空间**：选择已有白板，或新建主题白板。
2. **导入文献**：拖入 PDF，或点击「导入文献」，再在详情中校正自动提取的元数据。
3. **组织卡片**：拖拽排布、创建文字卡片、建立连线，或切换时间轴与图谱。
4. **调整展示**：画布上方「卡片显示」设置白板默认；选中卡片后，在右侧「卡片显示」独立调整。拖动卡片右下角可缩放。
5. **连续阅读**：打开 PDF 并选择平台内阅读，通过滚轮、触控板或滚动条浏览全文。
6. **批注与推导**：直接在 PDF 上书写，或在右侧新建关联笔记。独立笔记自动保存，PDF 墨迹需点击「保存 PDF」或按 `Ctrl + S`。
7. **专注模式**：画布右上角「专注画布」、笔记右上角「专注书写」、阅读页标题栏「专注阅读」可扩大当前工作区；`Shift + F` 切换，`Esc` 恢复。分屏笔记可独立专注，退出后回到原分屏；阅读专注模式保留阅读、钢笔、高亮、橡皮、颜色、粗细、缩放与 PDF 保存操作及 `Ctrl + S`。
8. **备份资料**：通过右上角「本地数据文件夹」查看并打开存储位置，备份整个目录。

## 本地数据与备份

默认数据目录为项目根目录下的 `data/`：

```text
data/
├─ workspace.json                  # 当前工作区、卡片、关系和笔记
├─ workspace.previous.json         # 上一次工作区备份
├─ notes/
│  └─ <note-id>.json                # 独立手写笔记，包含回收站项目
├─ conversations/
│  └─ <conversation-id>.json        # 本平台对话、来源、上下文与回答状态
├─ ai-codex/
│  └─ bridge.json                  # 本平台的 Codex 连接开关，不含登录令牌
├─ ai-auth/                        # 仅旧 SIWC 接入使用
│  └─ accounts.json                # 受保护的旧接入凭证与主机 ID，不可公开
└─ papers/
   └─ <file-id>/
      ├─ original.pdf              # 导入原件备份
      ├─ metadata.json             # 文件名、版本指针与校验值
      └─ revisions/
         └─ <revision>/
            ├─ document.pdf        # 嵌入批注后的 PDF
            └─ annotations.json    # 供平台继续编辑的矢量墨迹
```

建议先完成保存并停止服务，再复制整个 `data/` 目录。只备份 `workspace.json` 或导出的白板 JSON 不会包含 PDF 文件。

默认 Codex 接入的凭证由官方客户端管理，不保存在项目源码或 `ai-codex/bridge.json` 中。旧 SIWC 接入的 `ai-auth/` 含敏感凭证，Windows 使用当前用户专属 ACL，其他系统使用目录 `0700` / 文件 `0600`。不要将其提交、分享或纳入公开备份；只迁移文献与对话时可排除此目录，在新电脑重新授权。旧接入退出账号会清除本地令牌并尝试撤销远端会话，注册映射与主机 ID 会保留以供重新连接。

导入时保存的是资料库内的 PDF 副本，批注写入该副本，并保留原件备份。浏览器无法取得所选文件的原始绝对路径，因此不会回写导入前的源文件。

如果默认阅读器修改了资料库中的当前 PDF，本平台会检测变化并阻止覆盖。重新导入外部修改后的版本后，可继续批注。

## 配置

通过启动进程的环境变量配置本地服务：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PAPERLY_DATA_DIR` | 项目内 `data/` | 指定本地资料库的目录，建议使用绝对路径 |
| `PORT` | `4317` | 单独运行后端或 `npm start` 时的监听端口 |
| `HTTPS_PROXY` / `HTTP_PROXY` | 无 | 为 OpenAI 授权、身份签名验证与 AI 请求指定 HTTP(S) 代理；也支持小写变量 |
| `NO_PROXY` | 无 | 指定绕过代理的域名；本机回环地址始终直连 |
| `PAPERLY_CODEX_PATH` | 自动从 PATH 查找 | 指定 Codex 原生可执行文件或官方 `codex.js` 的绝对路径 |
| `PAPERLY_CODEX_HOME` | 沿用本机 Codex 配置目录 | 可选的独立 Codex 配置与登录目录，不复制现有凭证 |

Windows PowerShell 示例：

```powershell
$env:PAPERLY_DATA_DIR = 'D:\PaperlyData'
npm run dev
```

构建后服务使用自定义端口的示例：

```powershell
$env:PORT = '4318'
npm start
```

开发启动器与 Vite 代理默认使用 `4317`；`PORT` 不改变开发启动器的固定端口。本地后端不会自动读取 `.env` 文件；后端环境变量需在启动终端或外部进程配置中设置。

Codex 桥接继承启动进程的网络环境，联网行为由 Codex 客户端管理。旧 SIWC 接入的专用代理在启动后端时读取，不自动读取 Windows 系统代理设置。修改环境变量后需重启服务。

│  └─ backend.integration.mjs      # 后端集成测试
├─ src/
│  ├─ components/                 # 画布卡片、阅读器、笔记库与编辑器

│  ├─ card-model.ts               # 卡片外观继承与缩放

│  ├─ pdf.ts                      # PDF 解析与上传
│  ├─ pdf-ink.ts                  # 现有笔迹放入 PDF 的坐标处理

`data/`、`node_modules/`、`dist/`、`artifacts/` 和测试输出均不纳入版本控制。`tests/fixtures/` 中的 PDF 是项目生成的测试文件，可纳入仓库。

公开源码的隐私处理范围见 [发布说明](publication.md)。自定义资料库建议放在仓库目录之外，避免文献、聊天和凭证混入后续提交。

## 当前边界

- 当前为本地浏览器原型，尚未提供 Electron 安装包。
- 本地服务仅监听 `127.0.0.1`，无需登录；请在运行后端的同一台电脑访问，系统默认软件也在该电脑唤起。
- PDF 标题、作者与年份提取为启发式处理。扫描件或缺少元数据的文件可能需要手动校正；单文件上限为 100 MB。
- PDF 墨迹以矢量页面内容嵌入。在其他软件中可见，但不保证作为独立可编辑的 Ink Annotation 对象出现。
- 白板 JSON 导出不包含 PDF、Word、PPT 或图片二进制文件；完整迁移请备份整个资料库。
- Word 使用兼容编辑内核，复杂版式可能与微软 Word 有差异。PPT 平台内为静态预览，动画、视频和演示文稿编辑使用默认软件。
- Word 编辑器按需加载，首次打开会加载编辑内核；画布与图片操作不提前加载该内核。
- 示例论文使用演示排版，未打包对应的真实论文；可通过在线原文链接访问。
- 数位板真实压感取决于设备、驱动和浏览器的 Pointer Events 支持。已进行鼠标交互及压感几何验证，尚未使用真实数位板测量端到端书写延迟，也未完成 60 / 120 fps 性能基准测试。
- 撤销栈保留在当前编辑会话中，不作为永久版本历史。

## 开发约定

- 使用锁文件安装依赖，修改依赖时同步提交 `package-lock.json`。
- 功能变更应附带相应验证说明；按变更范围补充有意义的自动化测试。
- 本地论文、笔记、环境变量和生成产物存放在忽略目录中，避免混入源码提交。
- 更改数据格式时兼容已有工作区，并保持导入原件和保存版本的可恢复性。
