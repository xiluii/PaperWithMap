# 暗色模式验收

日期：2026-10-16。

## 行为

外观按钮提供浅色、暗色、跟随系统三种偏好，使用 `paperly:theme` 保存浏览器偏好。首次绘制前应用主题，系统变化与同来源标签页变化会同步；浏览器存储不可用时仍可在当前会话切换。

统一主题仅控制界面。PDF/PPT 页面、Word 正文、图片、笔迹数据与导出文件不做反色或改写。手写笔记的纯白、纯黑与黑板绿底色独立保存。

## 浏览器验证

在独立 `artifacts/reading-ai-qa-data/` 资料库中验证编辑器与关联笔记，不向真实 OpenAI 发送资料。

| 页面 / 功能 | 已验证内容 |
| --- | --- |
| 白板、图谱 | 卡片、连线文字、缩略图、浮动工具栏、显示设置、隐藏顶栏后的主题入口 |
| 文献库、笔记库 | 列表、搜索、筛选、空状态与三种笔记底色展示 |
| 共享弹窗 | 卡片默认设置、打开方式、主题弹层；Esc 关闭主题弹层后保留原弹窗 |
| Word | 原生编辑工具、原文黑字白纸、分屏关联笔记、专注编辑 |
| 手写笔记 | 黑板绿底色、笔具、设置、缩放与专注书写；界面配色独立于画布底色 |
| 图片 | 透明背景棋盘、原色预览、缩放、命名、备注和关联侧栏 |
| PDF / AI 侧栏 | 连续三页滚动至末页、批注工具、专注阅读、账号菜单、公式与表格、错误和正常状态 |
| 对话历史 | 历史列表、分页、输入框、账号重连与模型刷新、已有回答排版 |
| 外观偏好 | 浅色恢复、跟随系统、刷新后保持暗色 |
| 窄窗口 | 700 × 820 阅读器、上下分屏、主题菜单边界；检查后恢复默认窗口 |

PPT 使用与 PDF 相同的连续阅读组件；旧 DOC、PPT、PPTX 转换由既有集成测试覆盖。
