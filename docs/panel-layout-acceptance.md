# 独立阅读分页与可移动侧栏验收

日期：2026-10-17。使用独立测试目录中的合成 PDF、DOCX、图片、手写笔记及本地模拟 Codex，不读取或修改真实资料，不消耗账号额度。

## 本次行为

- 阅读器默认提供论文、手写笔记、AI 对话三个独立分页，手写与 AI 不再替换同一侧栏。可选择三栏并排，阅读区不足 1000px 时自动分页。
- PDF / PPT、Word、图片共用布局；Word 与图片的正文分页分别显示为文档、图片。
- 分栏保持稳定挂载。切页、收起、调整宽度、改变顺序时保留笔记笔迹、撤销历史、聊天草稿和编辑器状态。PDF 记住当前页；隐藏论文后解释公式也能使用该页。
- 导航、卡片详情、白板笔记、对话列表支持调宽和左右换边。阅读分栏支持调整相邻宽度与顺序。浏览器记住布局。
- 拖动把手平时透明，鼠标靠近边缘或标题把手、键盘聚焦和拖动过程中显示。侧栏位置把手位于顶部中间，避免遮挡关闭或展开按钮。

| 场景 | 验证结果 |
