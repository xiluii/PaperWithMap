# 阅读选区与当前页上下文验收

日期：2026-10-17。测试使用每页包含不同标识的四页合成 PDF、独立本地目录和模拟 Codex，不使用真实账号额度或发送真实文献。

## 问题与修复

- 已有对话此前默认沿用历史上下文，普通提问不会补充翻页后的资料。现在默认跟随选区或当前页，历史模式需显式选择。
- 原选区只传 PDF 文字，缺少公式和图形的视觉信息。现在在选区成立时保存局部截图，避免切换分页后丢失位置；公式提问复用此快照。
- 当前页严格使用阅读器维护的页码和已完成渲染的画布。隐藏论文分页后保留该页，不回退到 DOM 中的第一页；未渲染完成时给出重试提示。
- 新增框选提问，支持扫描页、公式和图表。框选不写入 PDF 批注，只有用户点击发送后才进入 AI 请求。
- 输入区显示选区页码或当前页，图像选区提供缩略图。正文点击或取消选区后清除旧选区，AI 输入与布局操作不会重新捕获旧文字。

## 浏览器与传输边界

| 操作 | 实际发送结果 |
| --- | --- |
| 修复前选中第 2 页公式 | 只有提取文字，图像数为 0，复现视觉信息缺失 |
| 第 4 页切换 AI 后普通提问 | 当前问题包含第 4 页专属文字，整页图像 1272×1800 |
| 第 4 页文字选区提问 | 页码为 4，公式为 `E_4 = x + 4`；局部图像 487×96 |
| 第 4 页矩形框选公式 | 页码为 4；局部图像 538×139，与框选位置一致 |
| 全文总结 | 输入含第 1、2、3、4 页各自的唯一标识，文献元信息为 4 页 |

检查了实际传入 Codex stdio 的图像与页码，局部图像确为第 4 页公式，未用第一页代替。模拟模型的固定回答不作为语义准确性证据。
