# 阅读研究工作区验收

日期：2026-10-17。使用独立数据目录、合成 PDF / DOCX / 图片、笔记及本地模拟 Codex。未修改真实文献，未发送内容给真实 AI。

## 设计与功能

应用 [UI UX Pro Max](https://uupm.cc/) 官方 skill 的 Flat Design、内容优先、拖动替代操作和 React ref 建议。保留平台主题和系统字体，未采用检索输出中的营销页布局。

- 新浏览器默认进入研究工作区：左侧论文，右侧白板和 AI 上下排列。保留已有布局偏好，可切换三栏与独立分页。
- 研究布局横线调整上下高度、竖线调整左右宽度；三栏分隔线调整相邻宽度。布局菜单提供滑杆和尺寸还原，键盘可操作。
- PDF 的工具归入论文栏，沉浸模式保留阅读、钢笔、高亮、橡皮、颜色、粗细、撤销、保存及缩放。删除重复提示、页码标签和常驻页脚。
- 手写笔记与白板工具栏支持收起、自由拖动、方向键、位置菜单与双击归位。位置及收起状态保存在本机，分栏或窗口变小时限制在画布内。
- 新增矩形和箭头，几何路径按现有笔迹格式保存，兼容撤销、橡皮、图片导出与放入 PDF。
- AI 模型、推理和发送范围按需展开，保留连接状态、错误与数据联网提示。文档、笔记和聊天在切换布局时保持挂载。

## 实机验证

| 场景 | 结果 |
| --- | --- |
| 拖动分隔线 | 竖线实际移动约 65px，横线移动 60px，论文、笔记、AI 独立调整 |
| 替代操作 | 主栏滑杆设置为 700px，横向分隔线用方向键将上栏缩短 16px |
| 白板形状 | 实际拖出矩形与箭头；与原有一笔合计三笔，关闭重开仍保留 |
| 沉浸 PDF | 钢笔写入一笔、保存成功；退出工具后仍可阅读和缩放；重开显示保存的一笔 |
| 浮动工具 | 实际把工具栏拖到右上方；收起、展开和窄窗口后仍可访问；AI 草稿不丢失 |
| AI | 展开模型设置，选择高推理强度，通过模拟 Codex 完成流式问答 |
| 主题与窄窗口 | 浅色、暗色及沉浸界面检查；375×812 自动分页，工具栏展开无横向溢出；测试后清除窗口尺寸覆盖 |

隐藏的手写画布不执行零尺寸初始化，避免先打开论文分页时把关联笔记缩成极小视图。
