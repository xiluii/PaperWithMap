# 光标与右键菜单验收

日期：2026-10-16。

## 实现范围

- 共用菜单组件负责定位、视口边界、焦点返回、禁用状态、键盘导航、快捷键、点击外部、滚轮与 Esc / Tab 关闭。菜单和操作错误提示适配浅色、暗色和专注模式。
- 画布、文件卡片、文字卡片、连线、文献库、手写笔记库、对话历史、PDF / PPT 预览、图片和手写画布提供各自的菜单，复用既有保存、关联与确认流程。
- 右键退出画布平移手势；抓手、空格、鼠标中键与滚轮仍用于平移。输入框、富文本、链接和 Word 正文保留浏览器或编辑内核的菜单。
- 可点击、选词、拖动、连线、卡片缩放、分屏、禁用和图片平移使用对应系统光标。钢笔、荧光笔、橡皮使用本地 SVG 光标，标记输入点；没有光标追踪动画或额外远程依赖。
- 复制卡片共享原文件，复制组内关系，保留自由画布位置，兼容时间轴恢复。移除卡片及连线可撤销，不删除原件。对话删除和笔迹清空继续经过现有确认框。

## 自动验证

- `npm test`：44 项 Vitest 与 45 项 Node 集成测试，共 89 项通过。
- 新增回归覆盖菜单的边界定位、键盘跳过禁用项与分隔线、循环导航、快捷键修饰键，以及卡片复制的关系范围、数据独立性、文件共享与时间轴位置恢复。
- `npm run build`：TypeScript 与 Vite 生产构建通过；Word 内核保留原有大体积分块提示。

## 浏览器实机验证

在独立端口及测试数据目录中使用合成 PDF、DOCX、图片、笔记和仿真对话，不修改个人文献，不发送真实 AI 请求。
