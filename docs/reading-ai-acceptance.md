# 阅读 AI 与对话历史验收

日期：2026-10-16。

本记录主要描述原 SIWC 接入及其回归验证。当前默认接入已改为本地 Codex App Server，真实账号与阅读页验证结果见 [Codex 桥接验收](codex-bridge-acceptance.md)。

## 已实现

- 阅读器右侧「手写笔记 / AI 对话」标签，兼容 PDF、PPT 预览、Word 与图片；保持分屏宽度、收起和专注模式。
- PDF.js 文字层与拖选快捷提问；选区、全文、沿用对话上下文三种范围。
- PDF / PPT 全文文字提取；Word 通过编辑内核的 `doc.getText` 读取当前正文；图片经本地缩放后作为视觉上下文。
- 公式解释可使用选区或当前 PDF 页截图，回答支持 Markdown、表格和 KaTeX。
- 官方 ChatGPT 套餐授权：动态客户端注册、PKCE、随机 state / nonce、JWT 签名与 issuer / audience / expiry 校验、刷新轮换、账号切换与退出撤销。
- 后端根据账号目录获取模型，以 Responses SSE 生成；明确处理额度错误、未完成、网络中断、停止及服务重启，不自动回退到付费 API。
- 对话和上下文保存在 `data/conversations/`；主页对话历史支持每页 20 条、全文搜索、文件筛选、重命名、删除、Markdown 导出、继续提问和返回文献。
- 回答保存为文字卡片，带来源对话与消息标识，和来源文献连线；重复保存不会重复创建。删除对话后笔记仍保留。

## 自动验证

`npm test`：31 项 Vitest + 26 项 Node 集成测试，合计 **57 项通过，0 跳过**。包括既有文件保存、DOCX 编辑稿修订、真实 DOC / PPT / PPTX 本地转换与新增 AI 用例。

新增验证覆盖：

- 真实签名 JWT 的 PKCE / nonce / state 校验、错误签名 / audience / expiry 拒绝、返回授权复用注册与主机 ID。
- 刷新令牌并发轮换、账号状态不泄漏凭证、退出撤销、外部 Origin 拒绝。
- 实际本地 HTTP 流、UTF-8 与 CRLF 逐字节分块、上下文保存、回答完成、中断、额度错误与缺失终止事件。
- 本地服务重启后的历史恢复、全文检索、23 条记录的第二页、文件筛选与删除隔离。
- 关联笔记必须先保存在白板，再写回对话；删除对话保留笔记。
- Markdown / LaTeX / 表格渲染，禁止回答自动加载远端图片或执行 HTML。
- OpenAI 专用 HTTP(S) 代理使用真实本地 CONNECT 代理验收，回环请求保持直连。
- 慢速令牌交换期间保持授权轮询，完成校验后再切换连接状态；取消中的回调不能激活账号。

`npm run build`：TypeScript 与 Vite 构建通过。保留原有 Word 内核较大资源包的构建体积提示。

## 需要实际账号完成的验证

未代替用户登录，未读取其他客户端账号凭证，未向 OpenAI 发送用户的真实文献。真实订阅的资格、模型权限、额度及联网生成，需要在平台点击 **Continue with ChatGPT** 并完成官方授权后确认。上游仿真验证不代表真实账号已成功调用。

全文文字上限 35 万字符，超限时明确报错而不截断。扫描件可用当前页截图提问，未集成全篇 OCR。Word 正文以外的页眉、脚注等内容是否可提取，受兼容编辑内核的正文接口范围影响。

官方协议依据见 [开发计划](plans/2026-10-16-reading-ai.md) 与 README。

## 授权超时排查补充

已修复后端忽略 HTTP(S) 代理，以及回调开始后过早停止前端轮询的问题。加入手动重新发起授权入口与验证阶段提示。

公开端点检查未发送文献或账号凭证：配置的代理可使 API 模型端点返回预期的未授权 JSON 响应；授权域名的发现与签名端点仍出现过连接超时。因此，不能声称系统浏览器中的 OpenAI 授权网页超时已经解决，仍需要实际账号重新走完授权与回调。
