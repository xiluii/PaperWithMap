# 源码发布与本地隐私

发布目标：<https://github.com/xiluii/PaperWithMap>。

仓库包含应用源码、依赖锁文件、开发文档和测试样本。个人文献、白板、手写笔记、对话上下文、登录凭证、浏览器验收截图与构建产物保留在本机，不随源码发布。

`.gitignore` 排除 `data/`、`artifacts/`、`node_modules/`、`dist/`、测试输出、环境变量文件、Codex 本地目录、认证与聊天目录、npm 凭证配置及常见私钥文件。公开提交使用 GitHub noreply 邮箱，初始提交中的私人邮箱不进入发布历史。

发布前对拟提交文件与 Git 历史检查密钥格式、私人邮箱、用户目录路径和带凭证的 URL，并检查 Office 测试文件的内部元数据。源码中认证字段的名称、环境变量名称和仅在测试中生成的仿真凭证属于实现与测试内容，不包含真实账号令牌。

PPT/PPTX 测试样本使用自制内容；作者、公司与最后编辑者元数据已匿名化。`node scripts/sanitize-office-fixtures.mjs` 可重新清理这两个固定测试样本，Office 样本生成脚本会自动执行该步骤。原始第三方 DOC 回归样本保留上游文件和出处说明。详见 [测试样本说明](../tests/fixtures/assets/README.md)。

后续发布前应检查暂存区：自定义数据目录建议设置在仓库之外；需要分享界面截图或导出白板、聊天时，应另行检查其实际内容。Git 忽略规则不会自动移除已经跟踪的文件。
