# Paperly 工作台布局规范

本次布局优化使用 [UI UX Pro Max 官方 skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/.claude/skills/ui-ux-pro-max/SKILL.md)，检索日期为 2026-10-16。

## 设计依据

- `productivity tool knowledge workspace --design-system --variance 3 --density 7`：采用匹配的 Minimalism & Swiss Style、简洁层级与功能色建议；生成结果中的营销页结构不适用于工作台，未采用。
- `productivity tool --domain product`：确认产品属于效率工具，优先内容、速度与明确的操作分组。
- `compact toolbar responsive --domain ux`：完整分组换行，避免页面横向溢出。
- `dragging movements --domain ux`：分屏除拖拽外，也提供单击按钮及键盘调整。
- `state keys --stack react`：保持节点、笔记与 PDF 的稳定标识；调整布局时不重建编辑器或文档。

## 全局约定

- 保留深蓝导航、白色内容面与青色操作强调；主要按钮使用现有 `#187e8b`，普通辅助文字使用 `#536879`。
- 采用本地系统字体，适配中文；正文与控件以 12–16 px 为主，重要标题以 21–26 px 为主。卡片自身缩放仍由用户设置控制。
- 以 4 / 8 / 12 / 16 / 24 / 32 px 组织留白；桌面内容边距 20–24 px，小屏 16 px。
- 桌面顶栏 48 px、白板模式栏 44 px，减少重复装饰占用。笔记库有内容时直接展示搜索与笔记，介绍仅用于空库。
- 列表与筛选保持清晰的对应关系，搜索栏在列表滚动时保持可达；长标题允许换行，并通过原生提示提供完整名称。

## 分屏与专注模式

- 阅读页由论文、手写笔记、AI 对话三个稳定挂载的独立分页组成，可三栏并排；调整布局不重建文档、笔记或对话编辑器。阅读区不足 1000 px 时自动切换分页。
- 三栏默认权重为 48 / 25 / 27；论文、手写、AI 的最小宽度分别为 360 / 300 / 340 px。拖动边界仅调整相邻两栏，尺寸限制以当前可用空间计算。
- 导航、详情、白板笔记、对话列表可拖动内边缘调整宽度，拖动顶部中间把手切换左右位置。阅读分栏通过标题把手排序。
- 把手默认透明，靠近边缘、键盘聚焦或操作过程中显示；不添加宽高过渡，指针事件通过 requestAnimationFrame 合并。支持方向键、Home / End 与双击还原宽度，位置也可用方向键调整。
- 宽度、左右位置、阅读顺序和阅读布局只保存在浏览器显示偏好中，不修改文献或笔迹。独立笔记专注时隐藏其他分栏及把手，退出后恢复原布局。
- 连续 PDF 阅读、笔记自动保存、PDF 显式保存及原有快捷键保持原有语义。

## 验证范围

以 375、768、1024、1440 px 检查列表、工具栏、分屏与恢复入口；检查键盘焦点、分屏按钮、范围边界与专注模式。动效遵循系统减少动态效果偏好，不在连续布局调整时添加宽高过渡。

## 对话界面

阅读侧栏与历史页共享正文组件和主题变量。正文 14px，历史页正文 15px，行高 1.8；标题通过字号、字重及上下间距区分。提问使用浅色块，回答保持开放的阅读区域。

代码块独立显示语言与复制操作，表格仅在局部横向滚动。输入框有可见标签，模型和推理控件使用原生选择框。邮箱与套餐放在账号菜单内，默认展示连接状态。手写笔记与 AI 各占独立分页或分栏；窄窗口使用单分页阅读，保留完整输入区。
