# 本地 Codex App Server 桥接验收

日期：2026-10-16。实际客户端：Codex CLI 0.157.1。

## 接入

默认 AI 提供方式改为 Codex 桥接，旧 SIWC 路径保留兼容验证。使用官方 stdio JSON-RPC 协议：`initialize` / `initialized`、`account/read`、`model/list`、`thread/start`、`turn/start`、`turn/interrupt` 与消息增量、完成事件。

使用 Codex 管理的 ChatGPT 登录；不会读取或复制 `auth.json`，不会提取浏览器 Cookie。只接受 `chatgpt` 登录方式，API Key 或其他凭证模式不触发推理。平台断开设置保存到 `data/ai-codex/bridge.json`，不调用共享账号的 `account/logout`。

每次生成创建 `ephemeral` 会话，以本地完整历史提供上下文，不在 Codex 的持久会话列表中新增文献对话。禁用 shell、执行器、插件、MCP 配置、浏览器及其他工具；设置只读沙箱；意外出现的工具或权限请求返回拒绝并停止本次生成。

## 已完成的真实验证

- 通过官方客户端读取本机 ChatGPT 登录状态，动态获取 7 个模型目录条目。
- 使用目录返回的默认模型，发送无个人文献的最小探测提示，收到三个文字增量与完成事件，最终内容为 `BRIDGE_OK`。
- 探测不读取用户的文献正文；功能页面验收使用独立 `artifacts/codex-browser-qa/` 合成资料库。
- 在阅读页将合成 PDF 全文（310 字符）发给默认模型，得到带第 1 页依据的中文回答。点击保存关联笔记成功，首页对话历史可继续查看该回答及已保存标记。
- 推理档位与默认值直接读取模型目录。默认模型返回低、中、高、很高、最高、超高六档；另一个模型仅返回前五档，切换时按实际能力更新。
- 使用默认模型选择「高」，就合成文献完成一次真实回答；界面显示思考阶段、回答正文与「推理强度 · 高」标记，本地 JSON 保存 `effort: "high"`。未发送个人文献。
- 阅读页与历史页共用流式状态和推理选择；各模型偏好保存在本机浏览器。暗色专注阅读的截图保存在 `artifacts/ai-stream-reasoning-reading.png`。
- `npm run build`：TypeScript 与 Vite 生产构建通过；保留既有 Word 编辑内核的大资源包提示。

## 自动验证

桥接 13 项集成测试通过。测试使用真实子进程与 stdio 管道，覆盖：

- 协议初始化、模型目录、UTF-8 字节拆分与状态脱敏。
- 文献完整上下文、历史回答与图像附件输入；本地记录可重新读取。
- 拒绝 API Key 登录下的推理。
- 停止、中断、并发会话隔离、额度失败和子进程崩溃；失败不误标完成。
- 未开放工具授权被拒绝。
- 平台断开跨重启保持，并且不退出共享 Codex 登录。
- 设备码登录与取消；缺少 CLI 时返回明确安装提示。
- HTTP 客户端在未完成的真实子进程回合中收到首个 Unicode 增量；停止后收到中断终态。
- 默认强度、显式强度、切换模型与缺少能力字段的旧目录；强度确实进入 RPC 请求并随历史落盘。
- 不支持的档位和错误类型在生成前返回 400，不新增消息、不启动 Codex 回合。
- 浏览器 SSE 读取器在响应关闭前逐段回调，处理跨字节 Unicode 和分隔符；缺少终态时报错。

`npm test`：33 项前端测试 + 39 项 Node 集成测试，合计 72 项通过，0 跳过。既有 PDF 墨迹、本地文件、DOCX 编辑、DOC/PPT/PPTX 转换与旧 AI 路径回归均通过。

## 使用边界

模型目录不是额度或权限承诺，实际请求以 Codex / OpenAI 的返回为准。ChatGPT 网页对话与 Codex 可用模型、额度及功能并不等同。设备码登录受账号安全设置或管理员权限影响。

文献、上下文与聊天继续保存在本机；发送的内容通过 Codex 联网传给 OpenAI，不能视为完全离线。官方 App Server 文档限制相关认证用于商业或托管服务，本项目当前仅监听本机回环地址。

官方依据：[App Server](https://learn.chatgpt.com/docs/app-server)、[认证](https://learn.chatgpt.com/docs/auth)。
